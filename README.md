# Kobi Org

O Kobi Org é um aplicativo web instalável para os assuntos de ancião: a pauta da
reunião, as designações e o cadastro de congregações e pessoas.

Acesse a versão publicada em <https://org.luizcmarin.com.br/>.

Para instalar no Android, no iPhone ou no computador, siga o passo a passo em
<https://org.luizcmarin.com.br/instalar.html>.

## Características

- funciona offline depois do primeiro carregamento;
- guarda os registros localmente no aparelho, cifrados;
- pode ser instalado como aplicativo no navegador;
- não exige uma conta, e não sincroniza com servidor nenhum.

## Privacidade e dados

Os registros ficam no armazenamento local do navegador. Eles não são enviados a este
repositório nem a lugar nenhum: o que sai do aparelho sai pelo backup, na mão de quem usa.

Limpar os dados do navegador, remover a instalação ou trocar de aparelho pode apagar os
registros. Use a função de backup do aplicativo antes de fazer uma operação desse tipo.
